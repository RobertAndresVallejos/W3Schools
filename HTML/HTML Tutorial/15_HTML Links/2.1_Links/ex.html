HTML Links

On trouve des liens dans presque toutes les pages web. Ils permettent aux utilisateurs de cliquer pour passer d'une page à l'autre.


Liens HTML - Hyperliens

Les liens HTML sont des hyperliens.

Vous pouvez cliquer sur un lien et passer à un autre document.

Lorsque vous passez la souris sur un lien, la flèche de la souris se transforme en une petite main.

Remarque : un lien ne doit pas nécessairement être du texte, il peut s'agir d'une image ou de tout autre élément HTML !

Liens HTML - L'attribut target

Par défaut, la page liée sera affichée dans la fenêtre actuelle du navigateur. Pour changer cela, vous devez spécifier une autre cible pour le lien.

L'attribut target indique où ouvrir le document lié.

L'attribut target peut prendre l'une des valeurs suivantes :

  • _self - Valeur par défaut. Ouvre le document dans la mêle fenêtre/onglet que celle dans la quelle il a été cliqué
  • _blank - Ouvre le document dans une nouvelle fenêtre ou un nouvel onglet
  • _parent - Ouvre le document dans le cadre parent
  • _top - Ouvre le document dans le corps entier de la fenêtre
