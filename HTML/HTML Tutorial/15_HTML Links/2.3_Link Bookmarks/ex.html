Liens HTML - Créer des signets


Les liens HTML peuvent être utilisés pour créer des signets, de sorte que les lecteurs puissent sauter à des parties spécifiques d'une page web.

Les signets peuvent être utiles si une page web est très longue.

Pour créer un signet, commencez par le créer, puis ajoutez un lien vers celui-ci.

Lorsque vous cliquez sur le lien, la page défile vers le haut ou vers le bas jusqu'à l'emplacement du signet.
