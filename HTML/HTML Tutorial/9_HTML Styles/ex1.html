HTML Styles

La balise "style" est utilisée pour ajouter des styles à un élément (couleur, police, taille, etc.)

Je suis rouge

Je suis bleu

Je suis grand


L'attribut de style HTML

On peut régler le style d'un élément avec l'attribut "style".
Exemple :
style="property:value;"


Couleur de fond

La propriété CSS "background-color" définit la couleur de fond.


Couleur de texte

La propriété CSS "color" définit la couleur de texte


La police

La propriété CSS "font-family" définit la police utilisée pour un élément.

Style : verdana

Style : courier


Taille du texte

La propriété CSS "font-size" définit la taille du texte.


Alignement du texte

La propriété CSS "text-align" définit l'alignement de texte horizontal pour un élément HTML."
