Éléments de citation HTML


HTML "blockquote" pour les citations.

L'élément HTML "blockquote" définit une section qui contient un extrait d'une autre source.

Voici une citation tirée du site web du WWF :

Depuis 60 ans, le WWF s'efforce d'aider les hommes et la nature à prospérer. En tant que première organisation mondiale de protection de la nature, le WWF travaille dans près de 100 pays. À tous les niveaux, nous collaborons avec des personnes du monde entier pour développer et fournir des solutions innovantes qui protègent les communautés, les espèces sauvages et les lieux dans lesquels elles vivent.

L'élement HTML "q" pour les citations courtes.

La balise "q" définit une citation. Mise entre guillemets.

Voici un exemple une citation avec des guillemets.


L'élément HTML "abbr" pour les abbréviations.

La balise "abbr" permet de donner une description aux abrévations ou aux acronymes via une bulle d'informations quand ont passe la souris dessus.Également, elle souligne en pointillés la partie ciblée.

L'élément HTML "address" pour les informations de contact.

La balise "addr" définit les coordonnées du propriétaire/auteur d'un document/article.
Les coordonnées peuvent inclure une adresse e-mail, une URL, un adresse physique, un téléphone. etc.

Exemple :

Rédigé par Jean Joe
Visitez-nous à l'adresse suivante:
Nike.com
Box 564, Nike
FR

L'élément HTML "cite" pour le titre du travail

La balise "cite" définit le titre d'un travail (un livre, un poème, un film, une peinture, une chanson, etc.)
Le rendu est en italique

The Scream de Edvard Munch. Peint en 1893.


L'élément HTML "bdo" pour l'annulation bidirectionnelle

BDO est l'abréviation de "Bi-Directional Override".
Ce texte sera écrit de droite à gauche
