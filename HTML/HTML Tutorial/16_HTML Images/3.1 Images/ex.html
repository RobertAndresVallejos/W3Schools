Images

Les images peuvent améliorer la conception et l'apparence d'une page web.


Syntaxe des images HTML

La balise HTML img est utilisée pour intégrer une image dans une page web.

Les images ne sont pas techniquement insérées dans une page web ; les images sont liéers à des pages web. La balise img crée un espace de stockage pour l'image référencée.

La balise img est vide, elle ne contient que des attributs et n'a pas de balise de fermeture.

La balise img possède deux attriuts obligatoires :

  • src - spécifie le chemin d'accès à l'image
  • alt - spécifie un texte alternatif pour l'image

L'attribut src

L'attrivut src obligatoire spécifie le chemin (URL) de l'image.

Remarque : lorsqu'une page web se charge, c'est le navigateur qui, à ce moement-là, récupère l'image sur un serveur web et l'insère dans la page. Veillez donc à ce que l'image reste au même endroit par rapport à la page web, sinon vos visiteurs verront apparaître une icône de lien brisé. L'icône de lien brisé et le texte alt s'affichent si le navigateur ne trouve pas l'image.

L'attribut alt

L'attribut alt obligatoire fournit un texte alternatif pour une image, si l'utilisateur, pour une raison quelconque, ne peut pas la voir (en raison d'une connexion lente, d'une erreur dans l'attribut src, ou si l'utilisateur utilise un lecteur d'écran).
