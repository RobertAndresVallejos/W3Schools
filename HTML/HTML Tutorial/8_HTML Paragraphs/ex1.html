Un paragraphe commence toujours sur une nouvelle ligne et est généralement un bloc de texte.


HTML Paragraphes :

La balise "p" signifie un paragraphe

Un paragraphe commence toujours sur une nouvelle ligne en ajoutant automatiquement un espace blanc (une marge) avant et après un paragraphe.

Affichage HTML

Le langage HTML et son en-tête de paragraphe ont quelques contraintes comme :
- les redimensionnement d'écrans créeront des résultats différents
- l'ajout d'espace ou de saut de ligne entre l'en-tête de début et de fin ne sera pas comptabilisé dans l'affichage .

Exemple :

This paragraph contains a lot of lines in the source code, but the browser ignores it.

This paragraph contains a lot of spaces in the source code, but the browser ignores it.

Sauts de ligne en HTML

La balise "br" définit un saut de ligne.
La balise br n'ayant pas d'étiquette de fin, est une étiquette vide.

des sauts
de lignes
